BIGDAVEBIG 7 — PORTFOLIO WEBSITE
=================================

FILES
- index.html : main portfolio website
- style.css  : styling, responsive layout, and light/dark theme
- script.js  : mobile menu, theme switch, contact form email handoff, active navigation
- cv.html    : editable starter CV page

HOW TO PREVIEW
1. Extract this ZIP to a folder on your computer.
2. Open the extracted folder.
3. Double-click index.html to preview in your browser.
4. Internet is required for the remote office photographs and Google Fonts.

HOW TO HOST ON RENDER (STATIC SITE)
1. Create a GitHub repository, for example: bigdavebig7-portfolio.
2. Upload index.html, style.css, script.js, cv.html and this README.md to the repository root.
3. In Render, choose New + -> Static Site and connect that repository.
4. Set Build Command to blank (or leave it empty) and Publish Directory to .
5. Deploy. Render will provide a public onrender.com URL if the deployment succeeds.

IMPORTANT CUSTOMISATION
- Contact email and WhatsApp number are set to the details previously provided. Confirm they are correct before publishing.
- The location is shown as Lagos, Nigeria; no home/street address is published for privacy.
- Office images are illustrative stock photos loaded from Unsplash; they are not evidence of a personally owned office.
- The contact form opens the visitor's email application. It does not send messages directly or store them. A working backend or form service would be needed for direct website submissions.
- The CV is a starter template, not a finished verified résumé. Replace bracketed sections and keep only accurate qualifications/skills before sharing.
- Project descriptions are deliberately modest. Add real screenshots, work samples and measurable results as you create them.
- This is a static site; no login, database or payment processing is needed for a portfolio.
